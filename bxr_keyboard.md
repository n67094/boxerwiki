# Keyboard Input Handling.

**NOTE:** `bxr_key_e` values are based on scancode (the physical location of
the key on the keyboard), not keycode (the character generated by the key
press, which can change based on keyboard layout and modifiers). To get the
key value of the current keyboard layout, use `bxr_key_name()` or
`bxr_key_name_ex()` with the appropriate modifiers.

## Public API

<a name="line-undefined"></a>
Get the name of a key in the current keyboard layout, using the given
modifier state.

`key` key to name, in `[0, BXR_KEY_SIZE)`.
`mod` modifiers to apply, as a bitwise OR of `bxr_keymod_e` values.

`return` the key name, or an empty string if there is no name for the key or
BXR_KEY_UNKNOWN is passed.

**Note**: the string is owned by SDL; do not free or modify it.

```cpp
BXR_API const char *bxr_key_name_ex(bxr_key_e key, bxr_keymod_e mod)
```

Check if a modifier is currently active.

`mod` modifier mask to check. Combined values such as `BXR_KEYMOD_SHIFT`
match either side. `BXR_KEYMOD_NONE` always returns false.

`return` true if any bit of `mod` is active, false otherwise.

```cpp
BXR_API bool bxr_keymod_pressed(bxr_keymod_e mod)
```
